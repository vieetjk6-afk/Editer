Học phong cách

Chọn các thư mục job bạn đã chỉnh xong (ảnh RAW + file .xmp cạnh nhau). Càng nhiều job, càng nhiều kiểu ánh sáng thì càng chuẩn. Học thêm job mới bất cứ lúc nào — tool chỉ đọc ảnh mới và cho biết độ chính xác tăng thế nào.

Đang dùng bản

Mã truy cập GitHub — chỉ làm 1 lần

Repo Editer để riêng tư (vì có ảnh và .xmp của khách) nên cần một mã chỉ-đọc để tải bản mới.

  1. Bấm (đăng nhập tài khoản GitHub của bạn).
  2. Token name: Editer · Expiration: chọn thời hạn dài nhất.
  3. Repository access: Only select repositories → chọn Editer.
  4. Permissions → Repository permissions → Contents: Read-only.
  5. Bấm Generate token, chép mã (bắt đầu bằng github_pat_) rồi dán vào ô dưới.

Mã chỉ lưu trên máy này (file cau-hinh.json trong thư mục dữ liệu), chỉ có quyền đọc, chỉ gửi tới GitHub.
